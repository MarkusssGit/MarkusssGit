## Selected projects

### Filtered PRM* for Maps of Dynamics-Aware Motion Planning
Master's thesis on human-aware robot motion planning using probabilistic roadmaps.

**Technologies:** C++, Python, OMPL, CMake, Linux

Developed and experimentally evaluated a probabilistic connection-filtering
approach for PRM* using pedestrian motion models. The method reduced roadmap
size substantially while maintaining reliable path planning.

### Human Trajectory Prediction for Socially Compliant Robot Navigation
Aalto University team project using the Boston Dynamics Spot robot.

**Technologies:** Python, ROS/ROS2, Extended Kalman Filter, sensor fusion

My contributions included implementing the Extended Kalman Filter used for
human state estimation, working with the ROS/ROS2 simulation environment,
and acting as project manager.

### Wearable Tremor Monitoring and Suppression Device
Embedded systems project using an Arduino Nano 33 IoT and two IMUs.

**Technologies:** C++/Arduino, MATLAB, FFT, digital filtering, GitLab

Worked as the software specialist, adapting the embedded software for the
project hardware and implementing signal-processing functionality for tremor
